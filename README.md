# Follow Your Dreams — Digital Experience v1.0 RC1

## Open locally

1. Extract the ZIP
2. Open the `FollowYourDreams_v1.0_RC1` folder
3. Double-click `index.html`

No installation or server is required

## Preview mobile layout in Chrome

1. Open `index.html`
2. Press `F12` or `Ctrl + Shift + I`
3. Press `Ctrl + Shift + M`
4. Choose a mobile device or use the Responsive option

## Main changes in RC1

- The map is no longer heavily cropped
- The lower, more artistic area is prioritised
- Both main reading moments last one second longer
- Narrative full stops have been removed
- The 404 transition is softer
- The route ends as a star

## Files

- `index.html` — structure and narrative
- `styles.css` — responsive layout and visual design
- `script.js` — timings, transitions, scroll effects and interactions
- `CHANGELOG.md` — RC1 changes
- `Follow_Your_Dreams_SSOT_v1.0.docx` — governing design brief
- `assets/mythic-map-background.png` — map artwork
